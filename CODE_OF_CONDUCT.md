# code of conduct

this project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

in short: be kind and respectful, assume good faith, & keep discussions about the mod.
harassment, insults and personal attacks are not tolerated in issues, pull requests or anywhere else.

## reporting

if someone breaks these rules, contact the maintainer privately through the contact options on [their GitHub profile](https://github.com/xeylou) or on [discord](https://discordapp.com/users/835863642498793483).
reports are kept confidential.

the maintainer may edit or delete comments, lock discussions, or block people who break these rules.
