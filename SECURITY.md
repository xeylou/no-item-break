# security policy

## supported versions

only the latest release is supported. please update before reporting.

## reporting a vulnerability

please do **not** open a public issue. report it privately instead:
https://github.com/xeylou/no-item-break/security/advisories/new

examples of what to report privately:

- a crash that a server or another player can trigger on purpose;
- a way to make the mod move or drop items it should leave alone.

## official downloads

builds are only published on this repository's releases page and on the mod's Modrinth page.
